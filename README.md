# ChatGPT Introduction Project

This repository contains debugging and introductory tasks for learning how to use ChatGPT in software development.  
Each directory includes hands-on exercises with Python, HTML, and JavaScript.

## Folders
- **debugging** — Contains all debugging tasks:
  - Python factorial debugging
  - Python argument handling debugging
  - HTML/JavaScript background changer debugging

## Purpose
This project demonstrates how ChatGPT can assist in identifying, understanding, and correcting code errors.
